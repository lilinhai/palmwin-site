README 与首页重写：说清掌窗是什么，配上产品图

原来的 README 只讲"这个仓库放什么"，读完不知道掌窗是干什么的；
首页也只有文字卡片，一张图都没有。两处都补上：

- img/ 新增 7 张产品图（与应用内 guide/images、drawable-nodpi 同源），
  首页按"它解决什么 → 两种形态 → 连上去 → 打中文 → 缩放 → 指针模式 → 工具菜单"
  的顺序铺图，每张都有 alt 与一句话图注。
- README 开头改成产品介绍：一段话讲清是什么、一张主图、
  四个常见问题的对照表、逐项功能配图、边界（不做什么）、最后才是仓库说明。
- 首页加 og:title / og:description / og:image，微信与企业微信分享时有卡片预览。
- style.css 补 figure / figcaption / img.hero / .duo 两列栅格（窄屏自动一列）。
