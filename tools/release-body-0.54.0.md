## 掌窗 0.54.0

安卓上的 Windows 远程桌面（RDP）客户端。这一版是上架前的准备版本。

### 这一版改了什么

**关于页补上提审要的两行**

- 新增「开发者」与「联系方式」。应用市场商户服务的「APP 未上架」分支要求关于页截图展示开发者信息，给不出就要先办软件著作权（30~60 个工作日）。
- 开发者写的是实名主体本人，联系方式只放邮箱。

**新增隐私政策**

- 应用内新增「隐私政策」页，设置页可进。内容十三节，逐条写清：不收集什么、数据存在手机哪里、密码怎么加密、网络只发往哪两个地方、申请了哪两个权限。
- 与应用市场提审表单里填的公网地址是同一份文件，逐字一致：
  <https://lilinhai.github.io/palmwin-site/privacy-policy.html>

**修正上一版一处本末倒置**

- 0.53.0 为了让「不含任何第三方 SDK」这句话成立，删掉了当时没在用的华为应用内支付依赖。功能边界由产品决定，不该为了让自己写的一句话成立去改产品。依赖已加回，删掉的是那句话，第三方组件改在隐私政策里如实交代。

### 安装

- 包名 `com.sinhy.palmwin`，`versionCode 64`
- minSdk 24（Android 7.0），targetSdk 36
- 签名证书 `CN=Palmwin`，SHA-256 `1461a72b8fdd332aa492e5f4647bae1d783a023737eb37046dece08ad1e21be7`
- 从 0.40.0 及更早版本升级需要先卸载一次（早期版本用的是调试证书），会清掉已保存的主机和密码，只做一次

### 权限

只有两个：`INTERNET` 与 `ACCESS_NETWORK_STATE`。
